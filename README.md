# pki-core-firmas 🔐

Funciona como una librería pura e independiente de Java. Se encarga del verdadero trabajo pesado: interactuar con los almacenes de certificados, manejar la criptografía con Bouncy Castle y estructurar firmas digitales robustas.

## ⚙️ Características Principales
* **Diseño Agnóstico:** Librería nativa y pura, libre de acoplamiento a frameworks web.
* **Criptografía de Alto Nivel:** Integración nativa con proveedores de seguridad (`Bouncy Castle`).
* **Abstracción:** Manejo estructurado de almacenes de certificados (KeyStores) y procesos de firma digital.

## 🚀 Implementación Práctica
Para ver un caso real de uso y cómo exponer los componentes de esta librería a través de un ecosistema de microservicios, revisa el proyecto **[FirmaDigREST](https://github.com/TU_USUARIO/FirmaDigREST)**.
